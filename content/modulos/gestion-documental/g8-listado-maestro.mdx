## El inventario de tu documentación

El listado maestro es una tabla con todos los documentos vigentes. Nada más, y nada menos: sin él, nadie puede responder cuántos documentos tiene la institución ni cuál es la versión buena de cada uno.

Es el mismo principio del inventario de equipos que verás en dotación. No puedes gestionar lo que no tienes listado.

## Las columnas

| Columna | Para qué |
|---|---|
| Código | Identifica el documento |
| Título | Lo describe |
| Tipo | Manual, procedimiento, formato, protocolo |
| Versión vigente | Cuál es la buena |
| Fecha de aprobación | Desde cuándo rige |
| Responsable | Qué rol lo mantiene |
| Ubicación | Dónde se consulta |
| Estado | Vigente u obsoleto |

## Dos usos en la vida real

**Encontrar rápido.** El verificador pide el programa de mantenimiento; se busca en el listado, aparece el código y la ubicación, y en dos minutos está sobre la mesa.

**Detectar lo que falta.** Cuando cruzas el listado contra los criterios que te aplican, ves de inmediato qué documentación no existe todavía. Es la forma más rápida de preparar una autoevaluación.

## El listado miente si no se actualiza

Este es el problema clásico. Se crea el listado, se llena con entusiasmo, y seis meses después tres documentos cambiaron de versión y el listado sigue igual.

Un listado desactualizado es peor que no tenerlo: da confianza falsa. Alguien busca la versión 2 porque el listado lo dice, y resulta que la vigente es la 4.

La regla es simple: el listado se actualiza **en el mismo momento** en que se aprueba un documento nuevo o una versión nueva. No después, no en la revisión anual.

## Vigencia y revisión periódica

Un documento no caduca solo, pero envejece. Dos prácticas ayudan:

**Fecha de próxima revisión.** Cada documento indica cuándo toca revisarlo, aunque nada haya cambiado. Un año es un intervalo razonable para documentación asistencial.

**Revisión por evento.** Hay cosas que obligan a revisar sin esperar la fecha: cambia una norma, cambia un equipo, cambia el servicio, ocurre un evento adverso, o una visita deja un hallazgo.

Revisar no significa cambiar. Si el documento sigue describiendo bien la operación, se deja igual y se registra que fue revisado.

## Cómo se retira un documento

Cuando un documento deja de aplicar, por ejemplo porque el servicio se cerró:

1. Se marca como obsoleto en el listado, sin borrar la fila
2. Se retira de todos los puntos de uso
3. Se archiva una copia para consulta histórica
4. Su código no se reutiliza

La fila se conserva porque los registros de años anteriores lo referencian. Borrarla deja esos registros huérfanos.

## Errores frecuentes

| Error | Consecuencia |
|---|---|
| Listado desactualizado | Se consultan versiones retiradas creyendo que son vigentes |
| Borrar las filas de documentos obsoletos | Los registros históricos quedan sin respaldo |
| Listado sin columna de ubicación | Sirve para contar documentos, no para encontrarlos |
| Incluir documentos que nunca se elaboraron | El listado promete algo que no existe |
| Actualizarlo solo una vez al año | Queda desfasado a los pocos meses |

El cuarto es delicado: si el listado registra un procedimiento que nunca se escribió, el verificador lo va a pedir.

## Cierre del módulo

Con esta lección terminas gestión documental. Lo que te llevas:

| Lección | Idea central |
|---|---|
| G1 | Lo obligatorio es que esté escrita y socializada |
| G2 | En el manual, un procedimiento es un acto clínico, no un papel |
| G3 | El código identifica, el título describe, la versión indica estado |
| G4 | Tres firmas con propósitos distintos y una fecha que no puede faltar |
| G5 | "Cuenta con" y "disponibilidad" deciden hallazgos |
| G6 | El documento describe lo que realmente ocurre |
| G7 | La versión sube cuando cambia cómo se ejecuta la actividad |
| G8 | El listado maestro se actualiza en el momento, no después |

De todo el módulo, solo dos cosas son exigidas por la Resolución 3100: que la información esté escrita y que esté socializada. El resto es lo que hace posible demostrarlo.

Con esto puedes pasar al módulo de dotación, donde vas a construir documentos reales sobre equipos biomédicos.
